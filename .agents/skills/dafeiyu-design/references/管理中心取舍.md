# 管理中心取舍

评审界面时，从一个用户动作追到事实所有者、窗口的读取权限和用户能核对的回执。用第二个窗口、重连或插件换代复验变化。[管理中心设计](../../../../文档/设计/管理中心设计.md)

| 评审对象 | 验证问题 |
| --- | --- |
| 房间与聊天 | 关闭窗口期间有新消息或身体移动，重开能否读到原状态？无法取样时是否能看出旧样本的时间？切换板块有没有影响主会话？ |
| 信箱详情 | 比较打开详情前后的消费游标、回信数与模型调用数。只有负责收件的接收方应改变业务回执。 |
| 配置表单 | 对比磁盘已保存值与当前实例已采用值。尝试旧修订、只读字段和重载后的旧回调，观察界面是否保留可核对的原结果。 |
| 插件板块与窗体 | 以计划中的测试插件分别验追加、替换、独立窗口及完整板块。先从计划核对当前已交付的范围，再区分需在本次验证的行为。 |

协议字段与窗口边界由管理中心设计维护。运行探针和排错见桌面手册，剩余交付见主题计划。[聊天与信箱](../../../../文档/设计/管理中心设计.md#主聊天与信箱) · [设置与实际采用](../../../../文档/设计/管理中心设计.md#插件管理与设置) · [桌面说明](../../../../文档/使用说明/桌面管理中心说明.md) · [管理中心待办](../../../../文档/开发计划/管理中心开发计划.md#待办)
