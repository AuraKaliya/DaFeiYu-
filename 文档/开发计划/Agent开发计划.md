### 三轮讨论确定的方向

| 主题 | 讨论结论 |
| --- | --- |
| 经历与主题记忆 | 经历按轨迹保留，值得记住的经历进入长期记忆。同批工具调用与回执构成一个节点，按工具规则标记并清理可丢弃的数据，保留来源、关键实效及必要证据。大肥鱼从经历中形成自己对自身和世界的认识，整理为可随新证据修订的主题记忆。 [人格演变讨论](参考/记忆与人格演变讨论记录.md) |
| 纠正的适用范围 | 近期语境足够清楚时，由大肥鱼判断范围，可以只标一个维度的一个区间。范围拿不准时先保留经历，等后续反馈补证。两次纠正仅在重叠部分取后接纳的版本，其余仍适用旧版。程序可用范围覆盖和原件引用验证此规则，当前试点覆盖已登记的条件。 |

| 联想与查证 | 程序可把浅层候选带入本次送模，大肥鱼需要深查时经工具取得下次送模的证据。语义相似负责候选，稳定登记信息和授权负责确认对象。「狼来了」用来验收能否联想起几次具体经历，回应由人格结合当前情况决定。 |

### 建议的实施顺序与验收

1. 先评审可追溯的近期摘要。建议从主人私聊、宿主保留表和有引用的接续摘要开始，用待定纠正、最近目标修订、待答和未核实工作验证首包。提交新的压缩视图前，每条摘要引用须能按当前档案和授权解析，仍待整理且将移出视图的反馈须有可恢复的原件。重复压缩、进程中断或撤权后再查一次，逐包核对原件、权限与工具配对。固定摘要验证程序约束，模型改述质量单独记录。[Agent-上下文-7](#agent-上下文-7)
2. 语义补漏可独立补齐 CLI 的编码器绑定、范围缓存、重启复用和回退。用相同快照、固定向量和固定模型响应核对外卖改述、退款及用途不明，真实改述命中与本机编码耗时按项目约定仅记录。[Agent-记忆-25](#agent-记忆-25)
3. 按已有可信任务号接续 T03。三组新读数分别验证已满足、待处理和未知，旧任务的读回仅说明当时的实效。自然语言指代和执行尚未完成的动作各自安排后续验收。[Agent-接续-1](#agent-接续-1)
4. 再选一种工具批次验收轨迹清理和回查，选一个跨话题样例验收联想，最后用一条客观观察和一条规律跑通知识检验。每阶段交付一个可独立验证的功能点。[轨迹与联想](#agent-决策-7) · [共享知识](#agent-决策-8)

## 立项理念与原始需求

同一玩家问进度时，模型既要知道原目标，也要知道当时实际入包多少、还有哪项在等人。原固定回放曾观察到规划读不到已经存在的库存、同组授权顺序改变请求、Hook 后用户实收文本与下轮引用不一致。计划据此拆开事实采集、决定送什么、执行和实际投递。让主会话和领域子会话共享可验收的执行语义，领域事实保留原所有者。

## 目标与范围

冻结每次逻辑决策的作用域和采样截止，提供可复算的消息与有序工具。明确模型所知、程序准入、实际效果、渠道实收和实际退出各自的证据。首批领域只切换一个 MC 绑定，普通聊天、规划、旧插件和非选定玩家仍走各自授权的正式入口。[Agent循环与上下文设计](../设计/Agent循环与上下文设计.md)
