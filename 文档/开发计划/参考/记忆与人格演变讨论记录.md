## 已确认的原则

- **记忆的作用。** 本体分层保存大肥鱼的个人经历，为个性化和人格演变提供依据，不设自动遗忘规则。记忆与本地知识库同属持久化数据系统，共用检索。知识库中的客观知识可以由人工收录，也可以由 Agent 提炼，均经过检验。大肥鱼在适用条件下采信已收录的知识，使用时判断时效和相关性，遇到冲突时分析并决定分辨、校正或标记删除。
- **主人的偏好和她自己的倾向各有归属。** “主人说他喜欢走陌生岔路”“我猜主人今天想走左边”“我自己喜欢探路”描述的是三件事。一次按主人要求留路标的行动也有它当时的任务背景。
- **大肥鱼可以从亲历中改变。** 她可以养成习惯，也可以逐渐改变对冒险的态度，这个过程无需主人确认。习惯描述她通常怎么做，态度描述有多种可行选择时她更看重什么。后来的经历可以让她加强、收窄或改变原有看法。
- **直觉可以先于解释。** 她能记得自己在怎样的情境里有过怎样的感觉。即使暂时说不清原因，也可以在下一项任务遇到相似情况时受它影响。

## 已认可的复盘区分

“在这种情况下，我通常怎么选”描述她的倾向。“今天回头看，我觉得当时为什么那样选”描述她的解释。两者可以分别变化，也可以同时变化。她能认出一个稳定习惯，仍然说不清它为什么形成。

| 探洞例子中的情况 | 这段经历可以说明什么 |
| --- | --- |
| 第一次迷路时，洞里既暗又没有回程标记。她记得自己当时很慌。 | **原因未明。** 这份感觉已经可以影响下次选择，光线和退路的影响尚难分辨。 |
| 险情过去后，她独自走陌生岔路，有余地直接赶路，却仍愿意花时间确认回程。有地图时，她就放心继续。 | **认出稳定倾向。** 她知道自己在陌生地方通常在意退路。同一态度可以表现为留路标或看地图。 |
| 她曾猜自己怕黑，后来却在明亮的迷宫里犹豫，在昏暗但回程清楚的地方很自在。 | **对过去有了新解释。** 当初的不安依然真实。如今她理解到，自己当时更在意能否找到回去的路。 |
| 面对与过去相近的陌生岔口，装备、目标和退路相近，也没有人催她，过去想折返的她如今主动提出再探一段，并享受探路。 | **她自己的倾向发生变化。** 她开始更愿意尝试未知。若当次向前只是因为主人让她赶路，那次行动只能说明当时的处境。 |

## 讨论过的分层方案

讨论曾用三个问题组织持久记忆。分层的原则已经确认，以下三个具体层次仍是方案。

| 拟议层次 | 这一层回答的问题 |
| --- | --- |
| 经历记忆 | 当时发生了什么？包括当事人、场景、原话、行动、实际结果和当时表达的感受。事后想到的理由另注明来源与时间。 |
| 主题记忆 | 我现在怎样理解这些经历？可以联系支持或反驳某种解释的经历，辨明判断属于谁、适用于哪些情形。 |
| 长期倾向 | 我在什么场合通常怎么做、做选择时更看重什么？讨论中的例子包括进陌生岔口时留路标的习惯，以及对冒险逐渐变得谨慎或大胆。 |

讨论中提过让上层理解能回查经历原件、区分当时的看法与后来的理解，并让当前决策按需取用相关内容。长会话压缩处理模型这一轮能看到什么。Claude 的记忆研究、Codex、billion-context 和 dsh-live-compact 的参考与适用边界见[记忆与知识库调研](记忆与知识库调研.md)。

## 讨论过的复盘时机

此前提出由大肥鱼判断何时值得回看。讨论列过四类情形。

1. **结果出乎意料。** 拿了火把仍想折返，新经历让“我怕黑”这个解释有了可对照的反例。
2. **同一种感觉再次影响了选择。** 可以比较当时有无别的选项、是否由主人交代、自己愿意付出什么代价。
3. **事情过后仍然惦记。** 独自找到出口后的喜悦、与主人相处时的信任或失望，也能成为回看的理由。
4. **眼前遇到取舍，或有人问起往事。** 即将折返，或主人问“你以前也这样吗”，都可能让旧经历重新有意义。

先应对急事，空闲时再回到有关的问题，是讨论过的做法。判断时可对照当时的原话、感受、可选行动和结果。一段往事被多次转述仍是一次亲历，受它影响后自主作出的新选择则是另一段经历。此前的建议没有为形成倾向设固定次数。一次深刻经历可以让她当场产生“以后我想这样做”的意愿，材料不足时也可以保留疑问。

动作的执行仍受当前任务、授权和现场约束。此前约定在记忆系统讨论之后再谈单主会话与子 Agent 的信箱协作。MC 跨局使用哪些经历或任务，要等本体记忆与知识库实际可用后再定。[主子会话议题](../Agent开发计划.md#agent-决策-5) · [MC 跨局范围](../MC伙伴开发计划.md#mc-范围-01)
