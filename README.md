# 大肥鱼

大肥鱼是一个 Windows 桌面伙伴。管理中心和普通聊天终端连接同一个常驻本体，空插件目录也能问答。MC 伙伴由独立的游戏角色进服，使用插件子会话处理玩家原话、场地观察和动作回执。
